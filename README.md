# Burgundy Cosmos · 个人作品网站

深空与勃艮第红的首屏、暖象牙白作品区，配合只在自己电脑运行的可视化工坊。公开网站使用原生 HTML / CSS / JavaScript，是纯静态文件；Node.js 仅负责本地编辑、图片保存和构建，无需安装第三方依赖。

## 打开预览

Mac 双击 **启动预览.command**，浏览器默认打开本地工坊：

- 工坊：`http://127.0.0.1:4174/workshop/`
- 独立网站预览：`http://127.0.0.1:4174/`

保留终端窗口，按 Control+C 停止。也可在本项目目录执行 `npm run dev` 后手动打开地址。需要 Node.js 20 或更新版本；双击脚本优先使用电脑中的 Node，找不到时使用当前电脑的 Codex Node 运行时。

桌面浏览器左侧工坊、右侧网站约为 1:4。工坊独立滚动，较窄屏幕保留可读的编辑宽度，手机改为上下排列。文字、作品、封面和顺序的修改会即时显示在右侧。文字提供预设字体风格和颜色。未保存修改关闭时会提醒。

## 四个页面与首页精选

顶部导航切换首页、图片作品、视频作品、广告作品。各分类页显示该分类的全部作品；首页使用图片列表前 6 项、视频列表第 1 项及广告列表前 4 项。可在工坊增加、删除和调整顺序。视频精选使用完整视口高度的展示区域。

初始内容是明确标注的**示例文字与待上传占位**，没有预填真实视频，请替换为你的作品。姓名、介绍、导航、分类标题、作品文字和页尾内容均可在工坊修改。宇宙首屏的视觉素材与作品上传数据分别维护，图片上传不会替换宇宙场景素材。

公开站通过 `#/images`、`#/videos`、`#/ads` 切换分页，刷新不需要服务器配置额外路由。请使用 HTTP 预览，不要直接双击 HTML 文件。

## 作品详情与社交主页

每件作品都有独立详情地址，例如 `#/images/image-1`，对应 `#/{分类}/{作品编号}`。详情支持直接打开、刷新、返回作品列表和前往下一个项目。原有四个导航分页和首页 6 张图片、1 个整屏视频、4 张广告的顺序继续保留。

在工坊选择作品后，可填写 **我的角色、设计过程、项目成果**；过程和成果支持回车分段。不填写的资料会显示待补充提示。点击 **在右侧预览这件作品详情**，即可一边编辑一边看详情效果。旧作品不用重新建立，新增字段均为选填。

详情页各区标题可在 **文字 / 风格 → 作品详情文字** 修改，默认依次为“关于作品、创作起点、创作过程、作品细节、创作收获”。

**详情图库** 支持每件作品最多 12 张本地图片，可一次选择多张，也可逐张更换、填写说明、用 ↑ ↓ 排序或删除。图库沿用封面的压缩流程，每张小于 2MB；图片说明最多 500 字。删除后原图片保留在本机素材目录，只有当前仍被封面或图库引用的图片才进入 `dist/`。

在 **文字 / 风格 → 社交主页（选填）** 填写自己的 LinkedIn、Behance、GitHub 主页。只接受对应官方域名的完整 `https://` 地址，留空就不显示可点击链接，不会替你生成账号或虚构联系方式。

详情数据仍集中在 `content/site.json`：每个作品的 `role`（最多 300 字）、`process`（12000 字）、`outcome`（6000 字）和 `gallery`（最多 12 项，每项含 `image` 与 `caption`）；全站社交信息存放在可选的 `socials.linkedin`、`socials.behance`、`socials.github`。通过工坊编辑时无需手动修改文件。

## 本地图片与 B站视频

图片和视频封面均从本机上传。工坊在浏览器中等比压缩为 WebP，最长边不超过 3000 像素，并继续调整画质或尺寸，直到**单张小于 2MB**。原图仍保留在你自己的电脑，压缩会有一定画质取舍。图片存储在项目 `public/media/`，不会上传第三方图片服务。

视频文件不上传项目，使用 B站官方内嵌播放器。工坊允许上传本地图片作为播放前封面。

例如你的链接是：

```text
https://www.bilibili.com/video/BV1xx411c7mD/?spm_id_from=333
```

保留到 **BV 编号结束**，删除 `?` 和后面的参数，即：

```text
https://www.bilibili.com/video/BV1xx411c7mD
```

在工坊的“B站链接 / BV 编号”框中，可以填上面截断后的链接、单独的 `BV1xx411c7mD`，也可以直接粘贴完整链接，工坊会自动提取 BV 号。`b23.tv` 短链需先用浏览器打开，再复制跳转后的完整链接。多集视频当前默认第 1 集；跟踪参数和 `p` 参数不会保留。视频能否站外播放由 B站和该视频的设置决定，页面同时提供 B站原页面链接。

## 保存与构建

点击工坊的 **保存并生成网站** 后，会将内容写入 `content/site.json`，同时生成或更新项目 `dist/` 目录。保存后页面显示成功状态；保存失败会显示具体原因。被当前作品引用的图片必须仍在本机项目中，若已丢失，请在工坊重新上传。

替换或删除作品后，原图片继续留在本机，避免误删；`dist/` 仅包含当前引用的上传图片。空作品列表或未上传图片均可保存和构建，网站显示相应的空白提示或占位。

手动检查和构建：

```sh
npm run check
npm test
npm run build
```

三个命令均无需安装第三方依赖。`check` 检查前端、本地工具和测试脚本语法、内容数据及部署合同。`test` 检查 B站链接处理、数据校验、媒体筛选、构建隔离、许可保留、本机接口限制及防止部署方式误改。测试用的构建位于系统临时目录。`npm run build` 会先运行部署合同检查，再执行原有静态构建；也可单独执行 `npm run check:deployment`。

先关闭本地工坊服务，再运行以下命令可单独检查最终公开产物：

```sh
node scripts/dev.mjs --dist
```

构建模式同样使用 `127.0.0.1:4174`，只提供 `dist/`；工坊、保存接口、上传接口和本地 QA 均无法访问。普通开发模式保留 `/__qa/verify.html`，用于宇宙场景的减少动态与 WebGL 降级检查。

## 固定部署流程

**现在尚未部署。** 等你确认网站，并在聊天发送 **部署** 两个字后，再按顺序引导：注册 GitHub、创建仓库并推送项目，然后注册 Cloudflare 并创建 **Cloudflare Pages 的 Git 集成项目**，获得 `项目名.pages.dev` 格式的链接。

后续 HTML、CSS、JavaScript 与页面可以大幅调整，部署方式禁止改变。固定合同已记录在 [AGENTS.md](AGENTS.md)、[deployment.json](deployment.json) 和 [DEPLOYMENT.md](DEPLOYMENT.md)。控制台首次连接仍需按下表配置：

| 设置 | 固定值 |
| --- | --- |
| 托管产品 | Cloudflare Pages，GitHub Git integration |
| 框架预设 | 无 / None |
| 构建命令 | `npm run build` |
| 构建输出目录 | `dist` |
| 项目根目录 | 留空；当前 `Burgundy Cosmos版` 目录作为独立 Git 仓库根目录 |
| Node.js | 构建主版本 24，由 `.node-version` 固定 |
| 生产分支 | `main` |
| 生产分支自动部署 | 开启；构建监视使用默认全部路径 |

GitHub 用于保存源码；公开站由 Cloudflare Pages 发布。以后更新流程为：**工坊修改 → 保存并生成网站 → Git 提交并推送 → Cloudflare Pages 自动构建 → 线上更新**。构建需要一些时间，本地保存本身不会自动提交或推送 Git。

首次上线后复用同一个 Pages 项目及 `pages.dev` 地址；不切换 Workers、Direct Upload、GitHub Pages 或其他发布工作流。部署检查失败时恢复误改项，不绕过检查或更换部署方法。完整首次推送和平台配置步骤见 [DEPLOYMENT.md](DEPLOYMENT.md)。

Git 提交应包括网站源码、`content/site.json` 和 `public/media/`。`dist/` 已加入忽略列表，由 Pages 使用同一个构建命令生成。请勿把 `content/` 或 `public/media/` 加入忽略列表。

## 发布隔离与项目文件

只有 `public/` 的公开页面、脚本、样式、场景素材，当前引用的上传图片及生成的 `data.json` 进入 `dist/`。字体许可和素材署名随公开素材保留。工坊页面、API、本地工具、测试、项目文档、隐藏文件及源映射均不进入部署产物。

| 路径 | 用途 |
| --- | --- |
| `public/` | 公开网站与宇宙场景、字体、素材许可 |
| `public/media/` | 本机上传的压缩图片与视频封面 |
| `content/site.json` | 全站可编辑文字与作品数据 |
| `workshop/` | 仅本机可视化工坊 |
| `scripts/dev.mjs` | 只绑定 127.0.0.1 的预览与工坊服务 |
| `scripts/build.mjs` | 固定静态构建流程 |
| `scripts/check-deployment.mjs` | 构建前检查固定部署合同与原始构建入口 |
| `deployment.json` / `AGENTS.md` / `DEPLOYMENT.md` | 固定部署约定与后续维护规则 |
| `tests/core.test.mjs` | 核心功能与发布隔离检查 |
| `ASSET-SOURCES.md` | 项目素材来源说明 |

素材原作者与许可见 `public/assets/ATTRIBUTION.md` 及 `public/assets/fonts/` 下的 OFL 文件。公开产物会保留这些文件。
